# Security policy

WinGhost is pre-release software and currently has no supported production version.

Please do not publish suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting feature when it is enabled for this repository.
If that feature is unavailable, open a minimal issue asking for a private contact
channel without including exploit details.

Terminal escape sequences, clipboard behavior, URL handling, shell process
boundaries, configuration loading, and update delivery are considered
security-sensitive areas.
